ScoreClean 野球スコア清書アプリ v1.0

1. ZIPを展開してください。
2. index.html をブラウザで開くと基本機能が使えます。
3. スマホでオフライン利用・ホーム画面追加するには、フォルダ一式をGitHub Pages等のHTTPSサイトに配置してアクセスしてください。初回アクセス後はオフラインでも利用できます。
4. 試合情報・得点・打席結果を入力すると自動保存されます。
5. 「PDF出力・印刷」でブラウザの印刷画面を開き「PDFとして保存」を選択します。
6. JSON保存でバックアップし、JSON読込で復元できます。

注意：画像のOCR自動読取・野球記号の自動判定は未実装です。原本を見ながら手動で清書します。端末のブラウザデータを消去すると記録が失われるため、JSONバックアップを取ってください。
