ScoreClean v1.1 — AI読取付きスコアブック清書アプリ

起動方法：通常の手動入力は index.html を開くだけで利用できます。
AI画像読取はオンラインで、OpenAI API利用料金が発生する場合があります。
AI機能を利用するには、Python 3 をインストールし、環境変数 OPENAI_API_KEY を設定した上で
  python ai_server.py
を実行し、http://localhost:8765 を開いてください。
解析API URL は http://localhost:8765/api/recognize としてください。
画像はAI解析サービスへ送信されます。公開サーバーに置く場合は認証・HTTPS・利用制限を追加してください。
APIキーはブラウザの入力欄や配布ZIP内に書かないでください。

使い方：撮影・画像選択 → AI読取開始 → 読取結果のJSONを確認・修正 → 確認した内容を反映。
既存入力欄は上書きせず、空欄のみ補完します。JSONエクスポートでバックアップしてください。

制限：手書き記号・進塁経路・重なった文字の認識精度は保証できません。
打席結果は各イニングの既存テキストマスに転記します。印刷用のダイヤモンド図形や
手書き線の幾何学的な完全再現は未実装です。AIはオフラインでは動作しません。


v1.2: SVGスコアマス描画（打撃記号・進塁線・アウト・注記）、チーム/打順/回別の図形保存、原本画像の手動格子位置合わせ、AI diagramsフィールド取り込み。位置合わせは手動であり自動検出ではありません。図形データは別キーscoreclean.diagrams.v1に保存。
