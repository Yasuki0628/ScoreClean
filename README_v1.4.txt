ScoreClean v1.4 — 実画像による罫線検証とマス座標対応付け

起動: pip install -r requirements.txt; python ai_server.py; http://localhost:8765
AI利用時: OPENAI_API_KEY を環境変数に設定。画像はOpenAI APIへ送信されます。
検証: python validate_sample.py

1. 「写真から一括解析」を実行。
2. 検出した縦横の罫線を画像で確認し、打席エリアの開始縦線/横線番号、行数、列数を指定。
3. 「座標とAI候補をマス単位で照合」を実行。
4. AIが座標bboxと信頼度を返した候補のみマスに割当。65%以上が同じマスに含まれ、信頼度70%以上で、境界重複が少ない場合のみ対応付け候補として提示。
5. 「確認した内容を反映」で既存の空欄のみ補完。

制約: 添付実画像に対する罫線検出は実行済みですが、選手名・記号の正解ラベルがないためAI認識精度（正解率）は測定していません。画像全体の罫線候補には文字や二重線が混ざり得ます。開始線は目視指定が必要です。AIがbboxを返さない場合はマス照合を実行できません。各マス内の複数打席・選手交代の完全再現は未対応です。元のLocalStorageキーは変更しません。
